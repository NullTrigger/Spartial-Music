Spartial Music is an open-source Android music player with a dark, glassy interface.

Play the music you own, and stream what is legal to stream. Spartial Music reads
audio already on your device, and can play from YouTube Music through an
unofficial client. Nothing is downloaded, extracted or kept from YouTube.

FEATURES
- Five floating tabs: Home, Trending, Suggestions, Library and Search
- Full-bleed Home hero, recently played, continue playing and daily shelves
- Now Playing with controls, credited synced lyrics and queue modes
- Word-synced lyrics where a source provides them, with the source credited
- Artwork-tinted backgrounds on Now Playing, Playlist, Album and Artist pages
- Playlists, pins, likes, recents, artists and local library search
- Add to playlist from any track surface, with undo and drag reorder
- Queue reorder, sleep timer, playback speed and skip silence
- Persistent queue, restored paused after a restart, with shuffle state
- Autoplay similar songs for an endless queue, and Reshuffle
- Device equalizer with presets, bass boost and virtualizer
- Library backup and restore to one versioned JSON file (no credentials)
- Listen Together: shared sessions over a room code, opt-in, on a server you
  choose, with a one-time notice about what is sent
- Media notification, lock screen controls and optional Cast (Google Play
  services build only)
- Settings for appearance, playback, lyrics, storage and diagnostics

PRIVACY
No accounts, no analytics, no advertising, no tracking. Your library never
leaves the device. Crash reports are written locally and are never uploaded.
Lyric lookups send the song title and artist to the sources you enabled; extra
third-party lyric sources are off by default. Sessions connect only to the
server you pick. Full detail: PRIVACY.md in the repository.

SOURCES
- Local device files through MediaStore
- YouTube Music through an unofficial InnerTube client (default source)
- Official YouTube Data API v3 provider and embedded player (code included)

The unofficial YouTube Music source is outside the YouTube API Services Terms
and may stop working when YouTube changes its private endpoints. Spartial Music
never downloads, caches or re-encodes YouTube media, never skips ads, and never
bundles a PoToken or attestation bypass.

DISTRIBUTION
The full build is intended for GitHub Releases and IzzyOnDroid. A separate
build without the unofficial YouTube source is planned.

LICENCE
